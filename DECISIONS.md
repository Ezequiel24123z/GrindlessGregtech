# Decisions

One line per decision. The most recent one is at the bottom.

- 2026-10-24 · Version: Minecraft 1.20.1 + Forge 47.4.x + GregTech Modern 7.5.3 (pinned) + KubeJS 2001.6.5. It is the latest stable GTM, it has the largest addon ecosystem, and it is where Monifactory, Star Technology, TerraFirmaGreg and GTL live. The 1.21.1 branch has had no stable release since July 2025, and 8.0 is in pre-release with a broken API.

- 2026-10-24 · Normal world (neither skyblock nor void as a start). Mining by hand is only for getting started and is never required to progress.

- 2026-10-24 · HV: syngas plant (`gtceu:syngas_plant`, type `gtceu:syngas`). It gasifies with steam, coal, coke, charcoal or powdered carbon, and the refinery's heavy fuel. It shifts CO with steam over an iron and chromium catalyst, and separates H₂, CO and CO₂, each gas to its own hatch. It also turns the excess CO in HV into H₂ (silicon, wood gas, Nether air). Recipes are based on real chemistry with GTM's units (steam counts as water, one mole per 1,000 mB; each recipe balances C, H and O), and the energy of the stages is summed. It does not reform methane (GTM already does that) and does not touch the reformer, which still runs on naphtha. CO₂ is inert in GTM: it can be discarded or used.
- 2026-10-24 · Quest book: every ID (chapter, quest, task, reward) has 16 hexadecimal digits, and the first one is between 0 and 7. Those were the floating quests the user saw: half of the book's IDs. `tools/quests/fix-ids.mjs` clears the high bit (deterministic, it can be run chapter by chapter); the linter flags it as an error, and `gg_test_quests` counts the loaded dependencies of each chapter.
