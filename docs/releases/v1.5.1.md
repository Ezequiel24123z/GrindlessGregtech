A fix for servers: EMI shows every GregTech recipe again when you play on a dedicated server, and the questbook lists the era chapters in tier order.

- EMI on servers: the GTM Extended Features addon builds example recipes for its universal disassembler, which the pack removed, and that step needs a singleplayer world. On a client joined to a dedicated server it failed and took down GregTech's whole EMI plugin, so no GregTech recipe, machine or category showed up. The pack now strips that leftover logic. Singleplayer was not affected. Checked with a test client joined to a copy of the play server: every audited item shows how it is obtained and used.
- Quests: the Progression group lists the era chapters from Steam to MAX+ in tier order (EV came after IV before).
- Tests: the EMI preview baseline no longer lists the assembly line array as a known gap, and the release gate picks the T0 run of a commit deterministically (#408, #409).

Upgrading: no new world needed. Restart the game so the instance updates; on a server, update the server pack the same way.
