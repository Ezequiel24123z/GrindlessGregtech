A performance and cleanup update: the quest book runs smoothly in the long late chapters, and the ambient mods are gone.

- Quest book: the UHV to MAX+ chapters dropped to a few frames per second. FTB Quests rechecked every quest's visibility each frame by walking its dependencies back to the first quest of the book. The generated chapters now use FTB Quests' cached visibility, so the book costs the same in every chapter. Nothing is hidden and no chapter is split; the test client checks that every quest stays visible.
- Mods removed: InvMove (walking with the inventory open), Item Highlighter (the new-item marker), AmbientSounds, Alex's Mobs with its library Citadel, Naturalist and Not Enough Animations. They added no progression and cost frames.
- Processing Lines chapters redrawn after the line audit (#413 to #415): some short feeders fold into their lines and a few charts gain the inputs they were missing. No recipe changes.
- Docs: a multiblock tutorial for contributors (`docs/multiblock-tutorial.md`).

Upgrading: no new world needed. Mobs and items from the removed mods disappear from existing worlds. Restart the game so the instance updates; on a server, update the server pack the same way.
