A small cleanup update: no more green item highlight, and a new picture-based multiblock tutorial.

- Mod removed: Inventory Profiles Next with its library libIPN. It drew the green highlight over items and the "NONE" profile selector in the inventory. It added no progression.
- Docs: `docs/multiblock-tutorial.md` is rewritten around drawings. A toy furnace teaches how to read a shape, then the Steam Vein Drill and the Submerged Arc Furnace show real machines, with a before/after reshape and the checklist we score shapes against.
- Tools: `tools/analysis/structure-svg.mjs` draws any multiblock (3D, pulled apart, or slice by slice) from its machine id or a small JSON file.

Upgrading: no new world needed. Restart the game so the instance updates. The server needs no change (the removed mods were client-only).
