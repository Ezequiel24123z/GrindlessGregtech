## What is broken or pending

- **v0.7.0 is not published yet:** isolated integration reruns and the final static checks must pass before tagging or moving `jugable`. The playable channel remains v0.6.1.
- **Open risk:** fires outside GTM's recipes (vanilla furnaces, AE2's vibration chamber, Farmer's Delight stoves) still burn on the Moon. Vanilla furnaces on Mars are kept on purpose: the first merrillite is smelted in one.
- **Wireless EU is being built separately:** the user's requirement is one global, multidimensional network from LV, with ordinary-machine covers, multi-amperage energy/dynamo hatches (including 64 A) and a large battery tower. Cell upgrades must unlock matching voltage tiers. This replaces the earlier per-team proposal; completion awaits actual cover, conservation, persistence and cross-dimension proof.
- **The Steam multiblock projector is being built separately:** right-click for a hologram, sneak-right-click to place default structural blocks from inventory. It must never place hatches or other interchangeable machine parts.
- **The Power reference tab is being built separately:** generation, fuel lines, storage and transmission through IV, linked to the existing quests/charts. Wireless entries wait for working mechanics.
- **Early starter improvements requested, targeting v0.7.1:** an HV-tier prospector from the beginning, with actual 16-chunk reach, unlimited energy and fast scanning; diamond tools with Efficiency V and 64 food. Keep the existing neutronium toolbox. This work is isolated from the IV release candidate; scanner behavior still needs source investigation and a real-client proof.
- **LuV design is written and reviewed on its own branch:** 20 progression multiblocks, with a fallback if a second orbital station is not supported. No LuV implementation or native spike has landed.
- **Public Modrinth/CurseForge distribution and promotion are deferred at the user's request** until the pack is finished.
- **VM:** the user raised the VM's dynamic RAM from 8 to 14 GB after the crash. About five child sessions and a few background agents run at a time; free memory sits near 2 GB, so new work starts as old work ends.
