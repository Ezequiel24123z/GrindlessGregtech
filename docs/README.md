# Documentation

Players only need the [README](../README.md). This folder is for anyone curious about how the pack is designed, or who wants to work on it.

## Design

- [journey.md](journey.md): the whole progression, tier by tier.
- [eras](eras/): the design of each tier, with its places, machines, processing lines and costs. [eras/maxplus.md](eras/maxplus.md) covers the last tier and the Hyperstargate, and [eras/mega.md](eras/mega.md) the mega multiblocks, which run huge parallels or do the work of several machines at once.
- [quests.md](quests.md): how the quest book is organised and written.
- [research](research/): the research behind the tiers, such as complexity targets, other packs and the GTNH Stargate used as a reference for the Hyperstargate.

## Releases

- [releases](releases/): notes for every version since v0.9.0.

## Development

- [STATUS.md](STATUS.md): where the project stands and what is still open.
- [multiblock-tutorial.md](multiblock-tutorial.md): how to add or improve a multiblock, step by step.
- [testing](testing/): the test bench, the validation server and how to run them.
- [quality](quality/): the standards for recipes, structures, items, EMI pages and sounds.
- [reforge](reforge/): the v1.0.0 rework, including the cost model, the line audit and the asset audit.
- [integration](integration/): a design draft for bringing technical and magic mods into the pack through GregTech.

Design decisions are logged in [DECISIONS.md](../DECISIONS.md), and [CREDITS.md](../CREDITS.md) lists every source and licence.
